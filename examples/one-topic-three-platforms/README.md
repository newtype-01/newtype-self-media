# 一个母题，三种平台输出

母题：**为什么收藏了很多 AI 提示词，工作效率还是没有提高？**

这个案例展示同一个中心判断如何分别进入公众号、小红书和短视频。它的目的不是提供可直接冒充个人经验发布的成稿，而是展示：

- 公众号负责把判断讲透。
- 小红书负责把问题讲具体并给出可收藏的动作。
- 视频负责把一个判断讲出来，并为画面执行留出位置。

## 文件顺序

1. `教学素材.md`：允许使用和不能假设的材料。
2. `母题卡.md`：跨平台共同判断。
3. `公众号文章/`：选题卡、初稿、终稿与发布清单。
4. `小红书图文/`：选题卡、正文、图文页和封面方案。
5. `视频脚本/`：选题卡、口播稿、分镜与素材清单。
6. `三平台转换说明.md`：哪些内容保持不变，哪些必须重做。

使用自己的项目时，应替换为真实经历、真实读者问题和可核查事实。
