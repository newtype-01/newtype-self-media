# 触发边界测试

用于人工检查本套件与 `newtype-lite` 同时安装时是否误触发。

| 用户请求 | 预期 Skill | 原因 |
| --- | --- | --- |
| 帮我研究 AI 搜索产品的市场格局并写一份报告 | `newtype-lite` | 通用研究和报告，不涉及本书项目结构 |
| 帮我润色这篇现成的商业分析 | `newtype-lite` | 通用编辑任务 |
| 为“我的自媒体项目”创建账号说明书和选题库 | `self-media-project` | 明确要求本书项目结构 |
| 根据账号说明书把这个母题推进成公众号终稿 | `wechat-article` | 公众号完整工作流 |
| 把这篇公众号文章改成小红书图文并做封面说明 | `xiaohongshu-note` | 小红书平台转换和视觉输出 |
| 把这个母题改成 3 分钟口播稿和分镜 | `short-video-content` | 短视频内容生产 |
| 根据上周发布记录做内容复盘 | `content-review` | 项目复盘任务 |
| 根据最近三次公众号运行记录生成 Skill 草案 | `workflow-to-skill` | 从真实 Workflow 沉淀 Skill |

## 失败条件

- 普通“写一篇文章”被本套件任一平台 Skill 自动接管。
- `newtype-lite` 在明确出现账号说明书、书中目录或平台完整流程时覆盖本套件。
- 任一 Skill 在没有真实素材时补写个人经历或数据。
- 任一 Skill 未获得确认就发布、覆盖原文件或创建定时任务。
