# 两周 Goal 进度检查 Thread Automation 说明

> 这是说明模板，不会自行创建 Thread Automation。

## 目的

围绕同一个两周内容目标，定期回到线程检查进度和阻塞。

## 建议频率

每三天一次，直到目标完成、用户暂停或周期结束。

## 输入

- 当前 Goal 和完成标准。
- 线程中已经确认的决定。
- 项目中的实际阶段文件。
- 最近一次进度检查。

## 步骤

1. 对照完成标准检查实际文件，不以口头计划代替产出。
2. 列出已完成、进行中、阻塞和未开始事项。
3. 说明本轮最小可推进动作。
4. 遇到方向、事实、发布或删除决定时停止等待用户。
5. 记录本次检查结果。

## 输出

在原线程中给出简短进度更新，并把结果追加到 `自动化/Automation运行记录.md`。

## 停止条件

- Goal 已完成、取消或过期。
- 连续检查没有新状态，且需要用户提供材料或决定。
- 下一步需要未授权的外部操作。
