# 公众号文章

## 生成三个角度

```text
请读取账号说明书、选题库中对应母题和素材库中的相关材料。

先不要写全文。请给出三个公众号文章角度，每个角度说明目标读者、读者问题、中心判断、可用素材、主要风险和建议结构。不要补写项目里没有的个人经历或数据。等待我确认角度。
```

## 从选题卡到初稿

```text
请基于已经确认的公众号选题卡和真实素材，先生成文章大纲，标出仍需补充案例或核查事实的位置。

我确认大纲后，再写公众号初稿。初稿要区分事实、推断和作者观点，并保存为新文件，不要覆盖选题卡或素材。
```

## 诊断和定稿

```text
请诊断这篇公众号初稿，检查中心判断、解释顺序、素材真实性、事实来源、重复、空话和明显 AI 腔。

先只输出问题和修改建议。等我确认后再生成终稿、修改记录、标题备选和发布清单。不要覆盖初稿，不要自动发布。
```
