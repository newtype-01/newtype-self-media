# 小红书图文

## 从母题切平台角度

```text
请读取账号说明书、母题或公众号文章，以及素材库中的真实材料。

先判断这个主题是否适合小红书，再给出三个平台角度。每个角度说明目标读者、开头场景、正文结构、收藏价值、可用素材和风险。不要直接压缩公众号文章，等待我确认角度。
```

## 正文和图文页

```text
请基于已确认的小红书选题卡生成正文初稿和图文页文案。

正文使用短段落和清楚的信息层级；图文页按读者阅读顺序重新组织，不要机械切句。不得虚构个人体验。请把两个结果分别保存，并列出待确认事实。
```

## 封面和发布清单

```text
请先为这条小红书笔记提供三个封面方向，包括主标题、副标题、构图、视觉元素、文字区域和需要避免的内容。

先不要生成图片 Prompt。等我确认视觉方向后，再生成图片 Prompt、后期加字建议和发布清单。不要自动发布。
```
