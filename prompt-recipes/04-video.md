# 5 分钟以内的视频

## 视频选题

```text
请读取账号说明书、当前母题或已有文章，以及素材库和视觉素材中的相关材料。

先判断它是否适合做成 5 分钟以内的知识视频。给出三个角度，每个角度只保留一个核心判断，并说明目标观众、开头场景、适合画面和素材缺口。等待我确认。
```

## 口播稿

```text
请基于已确认的视频选题卡，先设计“熟悉场景—关键解释—最小行动”的口播结构，再写口播初稿。

句子必须能说出口，不要把公众号文章直接缩短。不得补写我没有提供的经历或数据。请估算时长，并标出需要试读确认的句子。
```

## 分镜和发布准备

```text
请基于已确认的口播终稿生成字幕重点、分镜脚本、素材清单、封面文案和发布清单。

每个分镜要说明画面目的和可执行动作。素材不存在时标为缺失并给替代方案，不要假设已经拍摄。不要自动生成、上传或发布人物影像。
```
