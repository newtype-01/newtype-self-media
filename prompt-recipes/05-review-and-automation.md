# 复盘、Goal 和 Automation 说明

## 周期复盘

```text
请读取指定周期内的发布记录、内容文件和已有反馈，生成一份内容复盘草案。

区分已观察事实、作者反馈和你的推断。总结完成项、有效做法、问题、资料缺口和下一周期建议。没有数据的地方写“无法判断”，不要编造表现或原因。
```

## Goal 进度检查

```text
请根据当前 Goal、完成标准和项目中的实际产出检查进度。

列出已完成、未完成、阻塞、需要我确认的判断和下一步。不要因为文件存在就判断内容已经发布，也不要替我改变目标。
```

## 项目健康检查

```text
请检查当前自媒体项目是否存在文件缺失、长期未更新的选题、已发布但未复盘的内容、没有来源的事实或流程阻塞。

只检查、整理和建议。不要删除、移动、覆盖文件，也不要自动发布。
```

## Automation 说明草案

```text
请把已经连续手动验证有效的复盘或健康检查任务，整理成一份 Automation 说明草案。

写清运行频率、输入、步骤、输出、停止条件、运行记录和人工确认点。只生成说明文件，不要创建 Automation 或 Thread Automation。
```
