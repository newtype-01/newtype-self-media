# 手动 Prompt 使用说明

这里的 Prompt 用于三种情况：

1. 读者还没安装 Skill，想先跟书完成一次任务。
2. 任务仍在试跑，不适合沉淀为 Skill。
3. 读者要明确指定某个阶段，而不是启动完整工作流。

Prompt 是一次任务的入口。它不会自动获得账号背景、素材、保存路径和人工确认点。使用前应把项目目录作为工作目录，并明确要求读取真实文件。

## 使用边界

- 把方括号里的内容替换为自己的真实信息。
- 不要把示例经历当成自己的经历。
- 要求 Codex 保留原文件，并把结果写入新文件。
- 涉及事实、产品功能和平台规则时重新核查。
- 任何 Prompt 都不代表自动发布、自动删除或自动创建 Automation 的授权。
