# 从 Prompt 到 Workflow，再到 Skill

## 把一次请求整理成 Workflow

```text
请阅读这条任务说明和最近的执行记录，把它整理成一条 Workflow。

写清适用场景、输入材料、执行步骤、人工确认点、输出格式、质量检查和保存规则。请指出仍然不稳定、需要继续试跑的部分，不要直接生成 Skill。
```

## 检查 Workflow

```text
请检查这条 Workflow 是否足够清楚，能不能被另一个人或 Agent 执行。

只指出步骤模糊、输入缺失、人工确认不足、输出或保存规则不清楚的问题，不要直接重写。
```

## 根据真实运行生成 Skill 草案

```text
请读取这条 Workflow 最近至少三次真实运行的输入、阶段产出、终稿、修改记录和复盘。

先比较哪些步骤稳定、哪些步骤可选、哪些地方经常失败、哪些判断必须由人完成。然后生成一个窄范围 SKILL.md 草案，包括 name、description、适用和不适用场景、必要输入、工作步骤、输出、检查和停止条件。

请保存到“skills草案/<skill-name>/SKILL.md”，不要覆盖现有 Skill，不要安装或发布。
```
