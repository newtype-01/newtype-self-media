# 项目、账号说明书和素材库

## 第一次内容任务

```text
请阅读我提供的原始材料，先说明材料里有哪些事实、观点和待确认信息。

然后根据我的目标生成一份可检查的内容草稿。不要补写我没有提供的经历、数据或来源。请把结果保存为新文件，并列出仍需我确认的地方。
```

## 创建项目结构

```text
请检查当前目录，帮我建立一个自媒体内容项目。

需要包含账号说明书.md、选题库.md、项目使用说明.md，以及素材库、公众号文章、小红书图文、视频脚本、视觉素材、发布记录和复盘记录目录。

先列出现有文件和拟新增内容。保留所有原文件，不要覆盖或移动已有资料。完成后说明每个目录的用途。
```

## 起草账号说明书

```text
请根据我提供的账号介绍、历史内容和目标读者，起草“账号说明书.md”。

写清账号定位、目标读者、核心主题、内容边界、表达风格、可以使用的事实、不能编造的内容和需要作者确认的事项。

信息不足的部分请列为待确认问题，不要替我决定。
```

## 整理选题和素材

```text
请读取当前项目中的账号说明书、旧内容和素材文件，整理选题库、素材索引和视觉素材索引。

区分真实事实、作者观点、候选想法和待核查信息。引用原文件路径，不要移动或改写原始素材。完成后列出最值得继续补充的材料缺口。
```
